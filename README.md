#PSet Botlzmann samplers

#Description

This repository contains a set of Python codes for testing a new algorithm for Boltzmann sampler for powersets. The repository includes codes that:
	- check the limit shape for strict partittions ('strictexact.py'),
	- check the limit shape for short strict partitions into squares ('shortsquare.py'),
	- evaluate the performance of the free size strict partitions sampler ('benchpart.py')
	- evaluate the performance of the exact size strict partitions sampler ('benchpartexact.py')
	- evaluate the performance of the free sampler for short strict partitions into squares ('benchpartsquare.py')
